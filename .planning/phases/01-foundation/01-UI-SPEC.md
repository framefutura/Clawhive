# Phase 01 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Tailwind CSS 3.4+ |
| Preset | not applicable |
| Component library | shadcn/ui |
| Icon library | Lucide React |
| Font | Manrope (matches OpenClaw macOS app) |

**Why shadcn/ui:** The CONTEXT.md and RESEARCH.md specify "shadcn/ui" as the recommended component library. It provides accessible, customizable components built on Radix UI primitives, with a dark/light mode design pattern that matches our needs. Components are copy-pasted (not npm-installed), giving full control over styling.

**Why Tailwind + shadcn:** Recommended by stack research. Rapid prototyping, dark/light mode support built-in, matches OpenClaw's Tailwind usage in its own macOS app.

---

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tight inline padding |
| sm | 8px | Compact element spacing, message inner padding |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding, panel gaps |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (full-screen panels) |

**Exceptions:** Chat message bubbles use `sm` for inner padding to keep message density high. Input area uses `lg` to separate from message list.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (messages) | 14px | 400 | 1.6 |
| Label (UI controls) | 13px | 400 | 1.4 |
| Heading (panel titles) | 16px | 600 | 1.3 |
| Display (empty state titles) | 20px | 600 | 1.3 |
| Code blocks | 13px | 400 | 1.5 (monospace: JetBrains Mono) |

**Why Manrope:** OpenClaw's macOS app uses Manrope. ClawHive should match for visual consistency across the ecosystem. Loads via `@fontsource/manrope` npm package.

### Ambient Glow Effect

During agent work, the chat input area pulses with a subtle glow:

```css
@keyframes glow-pulse {
  0%, 100% { box-shadow: 0 0 0 0 transparent; }
  50% { box-shadow: 0 0 20px 2px var(--glow-color, #3B82F680); }
}
```

- Glow color: `rgba(59, 130, 246, 0.5)` in dark mode, `rgba(37, 99, 235, 0.4)` in light mode
- Animation duration: 2s ease-in-out infinite
- Applied to: input container border/box-shadow
- No progress bar — glow is the only ambient indicator

**Accent reserved for:** Send button, focus rings, model picker active state, selected chat message, agent status indicator. Never use accent for decorative elements.

**Left Panel (240px):**
- Team section: Agent list with status dots
- Genes section: Active gene categories with color coding
- "+ New" button for creating agents/tasks

**Center Blackboard:**
- Information cards showing current state
- Status cards with key metrics
- Quick action bar
- Collapsible chat panel at bottom

**Design Principles (from DeskClaw):**
- Focus on current work, not historical data
- Clean information hierarchy
- Color-coded gene categories
- Contextual actions, not overwhelming menus

### Model Picker (Top Bar)

Dropdown in top bar showing current provider + model:
- Format: `[Provider Logo] Model Name ▾`
- Click opens dropdown with provider groups (Anthropic, OpenAI, Ollama) and model list per provider
- Model list fetched dynamically from provider API
- Selected model remembered on restart (via electron-store)

### File Upload

- Drop zone: entire input area supports drag-drop (highlighted border on drag-over)
- File picker: click 📎 button opens native file dialog
- Clipboard paste: Ctrl/Cmd+V with image data triggers upload
- Preview: thumbnails shown inline in input area before send, and inline in chat after send
- Supported types: images (PNG, JPG, GIF, WebP), PDFs, text files
